# n8n-nodes-lumen

Community nodes for [n8n](https://n8n.io) that connect to [Lumen](https://lumen.run), the process platform for human-in-the-loop workflows: create and look up Lumen requests, browse process templates, and (soon) react to request and step events from inside your n8n workflows. The package is MIT licensed, written in TypeScript, has no runtime dependencies, and is built to meet the n8n verified community node guidelines.
